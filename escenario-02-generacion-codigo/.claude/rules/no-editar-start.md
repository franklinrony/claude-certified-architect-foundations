# No editar start

`start/` es el ejemplo original. No lo modifiques, no lo reformatees y no crees archivos nuevos ahí.

El mismo cambio va en `end/`, con la misma ruta relativa. Si el arreglo es `start/catalogo/precios.py`, el archivo que se escribe es `end/catalogo/precios.py`.
